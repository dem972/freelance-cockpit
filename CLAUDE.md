# Finance Cockpit — working rules

`BRIEF.md` (French) is the design reference. When in doubt, ask rather than guess.

## Rules

- Small commits, one topic at a time, tests green before moving on.
- No tax rate or threshold without an official source (Urssaf, service-public, impots.gouv) and a
  verification date, in `packages/engine/rates/<year>.json`. Never write a rate from memory; flag
  any unverified rate.
- No new dependency without a one-line justification (PR / commit message), nothing published
  less than two weeks ago.
- Strict types (`strict: true`), no `any`.
- Lint + format + typecheck + tests in CI (GitHub Actions) on every PR.
- Document engine assumptions in `packages/engine/README.md`.
- UI text in French; code, comments and docs in English. Commits signed off (`git commit -s`).

## Technical invariants

- `packages/engine`: pure functions, no I/O, no `new Date()` (the date is a parameter).
- Amounts are integer cents (`Cents`), `bigint` in the database. Never floats for money.
- User settings (statut, VFL, Acre, VAT, parts, caisse…) are dated (`validFrom`): the engine gets a
  timeline of settings, not a fixed config.
- The API verifies the `Cf-Access-Jwt-Assertion` JWT (signature + audience); never trust the
  header alone.
- Secrets outside the repo (`infra/.env`, git-ignored). Non-root images, committed lockfiles.
- AGPL-3.0: keep the footer link to the source (`SOURCE_URL`).

## UI

- shadcn/ui (Tailwind v4) with the terracotta / cream theme in `apps/web/src/index.css`.
  `apps/web/src/components/ui/` is generated by the shadcn CLI (vendored, excluded from strict
  lint): add a component with `npx shadcn@4.21.0 add <name>` from `apps/web`, then replace `cn`
  imports with `@/lib/utils`.
- Chart series colours (`--chart-*`) are validated with the colour-blindness validator (dataviz) in
  light and dark. Any new series colour must pass it again.
- System fonts only (no request to a third-party font service).

## Agents (apps/agent, Python)

- LangGraph + Celery + pgvector, OpenAI. See `apps/agent/README.md`.
- The AI never invents a number: every amount comes from the API (engine). Every write goes
  through `interrupt()` and the user's approval.
- `mypy --strict`, ruff, pytest; dependencies via `uv.lock` with `exclude-newer`.

## Commands

```sh
pnpm install
pnpm dev                                  # api :3000 + web (Vite, proxy /api)
pnpm lint && pnpm format:check && pnpm typecheck && pnpm test
cd infra && cp .env.example .env          # AUTH_MODE=none for local development
docker compose up -d --build --wait       # http://127.0.0.1:8380
docker compose --profile prod up -d       # + cloudflared + backup (see infra/README.md)
infra/backup/test-restore.sh <age-key>    # monthly restore test
```
